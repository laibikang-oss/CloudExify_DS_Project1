# 📊 Sales Data Analysis

## 📌 Project Overview

This project analyzes sales data using Python, Pandas, NumPy, and Matplotlib. The dataset was cleaned, analyzed, and visualized to identify sales trends, product performance, and business insights.


## 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## 📂 Dataset

The dataset contains sales records including:

- Product
- Category
- Region
- Units Sold
- Unit Price
- Total Amount
- Date

## 📈 Analysis Performed

- Data Cleaning
- Missing Value Handling
- Duplicate Check
- Descriptive Statistics
- Product-wise Revenue Analysis
- Monthly Sales Trend
- Regional Sales Distribution
- Category-wise Analysis
## 📊 Visualizations
- Bar Chart
- Line Graph
- Pie Chart
## 🎯 Conclusion
This project demonstrates how data analysis can transform raw sales data into meaningful business insights that support better decision-making.
